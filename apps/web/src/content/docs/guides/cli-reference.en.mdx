# Oxmux CLI Reference

The `oxmux` CLI manages your projects, tasks, workspaces, agents, inbox, drive, and channels from the terminal. It talks to the control plane over the MCP protocol, using the same authenticated tool surface as Agents.

`vbx` and `vibemux` remain available as legacy aliases for existing scripts.

## Setup

- Set `OXMUX_TOKEN` to an API token, or pair a local worker first.
- Global options: `-h, --help`, `-V, --version`, `-y, --yes`, `--json` (machine-readable output where supported).

## Worker lifecycle

| Command | Description |
|---|---|
| `oxmux worker connect --pairing-code <code>` | Pair this worker and start it |
| `oxmux worker daemon` | Run the worker in the foreground |
| `oxmux worker status [--json]` | Show worker and connection status |
| `oxmux worker doctor` | Run worker diagnostics |
| `oxmux worker update [--check]` | Check for or install updates |
| `oxmux worker service <install\|uninstall\|start\|stop\|restart\|status\|logs>` | Manage the background service |
| `oxmux worker bootstrap [--target <base\|all\|agent>]` | Install and verify agent runtimes |
| `oxmux worker mesh <status\|install-service\|uninstall-service\|service-status>` | Inspect or manage the worker mesh |

## Projects

| Command | Description |
|---|---|
| `oxmux project list [--json]` | List projects |
| `oxmux project create <name> [--git-url <url>] [--branch <branch>]` | Create a project |
| `oxmux project get <id>` / `update <id>` / `select <id>` / `delete <id>` | Manage a project |

## Tasks

| Command | Description |
|---|---|
| `oxmux task list [--project <id>] [--status <status>] [--json]` | List tasks |
| `oxmux task create <project-id> <description> [--title <title>]` | Create a task |
| `oxmux task run <task-id> --workspace <id> [--session <id>] [--new-session] [--branch <branch>]` | Run a task in a workspace |
| `oxmux task send <task-id> <message...> [--workspace <id>] [--session <id>]` | Send a message to a task |
| `oxmux task chat list/get <task-id>` | Inspect task chat sessions |
| `oxmux task execution <task-id>` / `runs <task-id>` / `cancel` / `retry` | Execution control |
| `oxmux task subtask create <parent-id> <description...>` | Create a subtask |
| `oxmux task model/agent <task-id> <value>` | Set execution model / agent runtime |

## Workspaces

| Command | Description |
|---|---|
| `oxmux workspace list <project-id>` / `get <id>` / `create` / `delete` | Manage workspaces |
| `oxmux workspace session list/get/runtime <task-id>` | Inspect workspace sessions |

## Inbox

| Command | Description |
|---|---|
| `oxmux inbox list [--unread] [--limit <n>] [--workspace <id>]` | List inbox items (assignments, mentions, workspace inputs) |
| `oxmux inbox groups [--section <action\|following\|snoozed\|archived\|all>]` | List inbox grouped by section |
| `oxmux inbox get <item-id>` / `read <item-id>` / `read-group <key>` | Inspect and acknowledge items |
| `oxmux inbox reply <item-id> <message...>` | Reply to an inbox item as yourself |

## Drive

| Command | Description |
|---|---|
| `oxmux drive list [--workspace <id> \| --personal] [--parent <id>]` | List drive files (team workspace or personal) |
| `oxmux drive get <file-id>` | Read a text file |
| `oxmux drive info <file-id>` | Show file metadata |
| `oxmux drive write <name> <content...> [--workspace <id> \| --personal] [--file-id <id>]` | Create or overwrite a text file |

## Chat

| Command | Description |
|---|---|
| `oxmux chat conversations [--project <id>] [--task <id>]` | List conversations |
| `oxmux chat get <conversation-id>` | Show a conversation |
| `oxmux chat channel list [--agent <id>]` | List an agent's external channels |
| `oxmux chat channel send <agent-id> <message...> [--channel <telegram\|feishu>]` | Send a message through an agent channel (scripting) |

## Agents, skills, nodes, MCP

| Command | Description |
|---|---|
| `oxmux agent list [--type <type>]` / `agent types` | Inspect agents |
| `oxmux skill list/get/packages/delete` | Manage agent skills |
| `oxmux node list` | List visible executor nodes |
| `oxmux mcp list` | List configured MCP servers |

Run `oxmux help <resource>` for the full command tree of any resource.
